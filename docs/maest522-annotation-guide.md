# Разметка датасета для MAEST 522

Этот инструмент готовит локальный multilabel-датасет для трёх новых выходов MAEST:

- `Electronic---Minimal-Deep-Tech`
- `Electronic---Microhouse`
- `Electronic---RoMinimal`

Каждый трек оценивается сразу по всем трём стилям. Порядок выбора стилей внутри карточки свободный, но перед сохранением для каждого должны быть указаны `да`, `нет` или `не уверен`.

## 1. Установка и запуск

Из корня репозитория:

```powershell
.\.venv\Scripts\python.exe -m pip install -r requirements-annotation.txt
.\.venv\Scripts\python.exe tools\annotation_ui.py --db .\annotation-projects\maest522\annotations.db
```

Откройте [http://127.0.0.1:8522](http://127.0.0.1:8522). По умолчанию сервер доступен только локально. Не меняйте `--host` на сетевой адрес без необходимости: база содержит абсолютные пути к вашей фонотеке.

Для акустических fingerprints нужен `fpcalc` из Chromaprint. Если он не находится через `PATH`, передайте путь явно:

```powershell
.\.venv\Scripts\python.exe tools\annotation_ui.py `
  --db .\annotation-projects\maest522\annotations.db `
  --fpcalc C:\Utils\tools\fpcalc.exe `
  --ffmpeg C:\Utils\tools\ffmpeg.exe
```

Без `fpcalc` треки получат явный статус `unavailable`, и split всё равно можно создать, но защита от акустически одинаковых версий будет слабее. Для итогового публичного датасета рекомендуется полноценный fingerprint-run.

## 2. Импорт всех кандидатов

Создайте проект и до фиксации split импортируйте весь доступный пул. После freeze новые источники в этот проект добавить нельзя; если пул изменился, создайте новый проект.

Доступны два способа:

1. Указать путь к локальной папке или M3U/M3U8 на машине, где запущен сервер.
2. Выбрать M3U/M3U8 в браузере и отдельно указать базовую папку, относительно которой разрешаются строки плейлиста.

Для каждого источника задайте целевой стиль и роль:

- `Положительные кандидаты` — папка/плейлист предположительно содержит этот стиль.
- `Hard negatives` — похожие треки, которые часто путаются с этим стилем, но должны получить `нет` после прослушивания.
- `Неразмеченный пул` — материал без надёжной стартовой гипотезы.

Один и тот же файл или его физическая копия дедуплицируются по SHA-256. Трек, попавший из нескольких стилевых источников, показывается один раз, но получает несколько source credits.

## 3. Fingerprints и заморозка split

После завершения всего импорта:

1. Нажмите `1. Fingerprints` и изучите количество `available`, `unavailable`, `errors`.
2. Исправьте ошибки чтения или осознанно оставьте явный audit-status.
3. Нажмите `2. Зафиксировать split 70/15/15`.
4. Убедитесь, что `audit_clean` равен `true`, и сохраните `audit_sha256`.

В один group объединяются exact-копии, совпавшие acoustic fingerprints, один release и один нормализованный artist. Group целиком попадает только в один из `train`, `val`, `test`.

## 4. Создание очередей

Рекомендуемый порядок:

1. Создать blind-очередь `val`, раунд 1.
2. Создать blind-очередь `test`, раунд 1.
3. Создать стартовую очередь `train`, раунд 1.
4. После первого обучения передавать acquisition scores только для следующих `train`-раундов.

Каждый раунд выбирает до 100 кандидатов на стиль. При достаточном пуле 25 мест резервируются под hard negatives. Overlap между стилями уменьшает фактическое число уникальных карточек. Максимум — 1 000 credits на стиль, то есть до десяти раундов по 100.

Validation/test никогда не ранжируются student-моделью. API дополнительно запрещает active-learning train round, пока не зафиксированы обе blind-очереди.

## 5. Разметка на слух

Состояния:

- `да` — стиль отчётливо присутствует;
- `нет` — трек является отрицательным примером для стиля;
- `не уверен` — неоднозначный случай; при обучении эта ячейка будет masked;
- `не размечено` — работа по этому стилю ещё не завершена.

Горячие клавиши:

| Клавиша | Действие |
|---|---|
| `Space` | play/pause |
| `1`, `2`, `3` | выбрать строку стиля |
| `P` | да |
| `N` | нет |
| `U` | не уверен |
| `X` | вернуть в неразмеченное состояние |
| `J`, `K`, `L` | перейти к 20%, 50%, 80% трека |
| `Enter` | сохранить все три состояния и перейти дальше |
| `Backspace` | предыдущая карточка |

Предсказания teacher/student в интерфейсе не отображаются, чтобы не подсказывать ответ разметчику.

## 6. Возобновление, экспорт и backup

SQLite хранит очередь и append-only историю каждого изменения. Можно остановить сервер и продолжить позже с той же командой.

Кнопка `Экспортировать manifest` создаёт:

```text
<папка-базы>/exports/<project_id>/training.jsonl
<папка-базы>/exports/<project_id>/dataset_summary.json
```

Portable manifest не содержит абсолютных путей. В нём остаются SHA-256 track ID, group ID, split, три состояния, candidate roles и фиксированные offsets окон 20/50/80%.

Для резервной копии сначала остановите UI, затем копируйте базу:

```powershell
$backupDir = '.\annotation-backups'
[System.IO.Directory]::CreateDirectory($backupDir) | Out-Null
Copy-Item -LiteralPath '.\annotation-projects\maest522\annotations.db' `
  -Destination (Join-Path $backupDir 'annotations-backup.db')
```

Исходные аудиофайлы инструмент не изменяет. Browser-preview для неподдерживаемых форматов хранится отдельно в `preview-cache` рядом с базой и не входит в manifest.
